# 公開とリリース

## 公開する内容

- ソース、ビルド設定、依存ロックファイル、テスト、導入・設計文書、架空データの画面例をGitで管理します。
- `work/`、`node_modules/`、`test-results/`、ビルド結果の `dist/` はGit管理対象外です。
- 実運用の画面写真、利用者名、サーバー設定、認証情報はリポジトリへ追加しないでください。
- プラグインIDは既存インストールとの継続性のため `com.nito.viewport-read-receipts` を維持します。これは接続先や認証情報ではありません。
- Goモジュール名は公開先に合わせた `github.com/kazunito/mattermost-plugin-viewport-read-receipts` です。

## 公開前の確認

1. プロジェクト自身のライセンスはApache-2.0です。LICENSEとREADMEの表示を一致させます。依存ライブラリはそれぞれのライセンスに従います。
2. `make deps` で依存関係を導入します。
3. `npm --prefix webapp exec -- playwright install chromium` でテストブラウザを導入します。
4. `make check-style test` を実行します。
5. `make dist` でインストール用tar.gzとSHA256SUMSを作成します。
6. Gitの差分・管理対象ファイルを確認します。既存のローカル履歴も公開する場合は、最新ファイルだけでなく過去のコミットも確認します。

GitHub Actionsの設定は `.github/workflows/ci.yml` にあります。公開先での初回成功を [GitHub Actions](https://github.com/kazunito/mattermost-plugin-viewport-read-receipts/actions/runs/40430355336) で確認しています。CIでテスト・ビルドが通ることと、実機での受入確認は別です。

## GitHubへの公開

公開先は [kazunito/mattermost-plugin-viewport-read-receipts](https://github.com/kazunito/mattermost-plugin-viewport-read-receipts) です。ソースはmainブランチで公開しています。

GitHub Releasesでは、ソースのタグに対応する次の2ファイルを添付します。

- `dist/com.nito.viewport-read-receipts-0.1.2.tar.gz`
- `dist/SHA256SUMS`

GitHubが自動生成する「Source code」は開発用ソースです。Mattermostのプラグイン管理へアップロードするのは、上記のインストール用tar.gzです。[GitHub公式のリリース説明](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases) を参照してください。

## バージョンと動作状況

0.1.1は公開前のフォルダ構成・ビルド・説明の整理です。0.1.0から表示検知・API・データ形式を変更していません。構成整理だけを理由に、動作中の0.1.0を再インストールする必要はありません。

実機で報告されたのはインストールと人数・名前一覧の基本表示です。画面外・背景タブ・各スレッドの判定、実デスクトップアプリ、負荷・再起動・期限切れ処理をすべて受入済みとはしていません。公開時にはこの確認範囲を説明してください。

0.1.2では管理画面の表示名を `Viewport Read Receipts` に変更しています。日本語の説明・設定項目とプラグインIDは維持しています。表示名を反映する場合は0.1.2のインストール用tar.gzで更新してください。
